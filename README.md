# PerfecPlay Eklenti Merkezi

PerfecPlay tarafından sunulan CloudStream `.cs3` eklenti koleksiyonudur.

## CloudStream repo adresi

```text
https://raw.githubusercontent.com/perfecplay/kraptor-cs/refs/heads/main/repo.json
```

Bu arşiv 72 adet `.cs3` dosyası içerir. `plugins.json`, kaynak manifestte listelenen ve dosyası mevcut olan 66 eklentiyi sunar. Kaynak manifestte liste dışı bırakılmış 6 dosya arşiv amacıyla korunmuştur.

> Eklentiler üçüncü taraf sitelere bağlıdır. Bazıları zaman içinde çalışmayı bırakmış olabilir.
